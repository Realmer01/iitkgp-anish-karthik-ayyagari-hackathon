# Data card

Every file the prototype uses is in this folder, together with the script that produced it. Nothing is
proprietary, and nothing comes from S&P Global or Crisil (no client data, names or engagement details).
Connectors drop anything published by S&P Global, Crisil or their businesses (`ingestion/base.py`); 46 S&P
Global articles indexed by Google News were removed from the archive for this reason. Third-party news that
only mentions either firm (for example a reported public rating action) is kept as ordinary public news.
Real data is public; everything synthetic is generated by a seeded script and labelled as synthetic.
Retrieved 6–7 October 2026. Committed size about 15 MB; no file exceeds 5 MB.

## Labelled evaluation set

| File | Content |
|---|---|
| `labeled/gold_sample.csv` | 400 real headlines from `news_history`: 250 uniform random + 150 targeted at rare risk classes, shuffled (`scripts/build_gold_sample.py`, seed 2026) |
| `labeled/gold_labels.csv` | Event type (12 classes) and sentiment (negative / neutral / positive) per headline |

**How the labels were made.** One annotator (the author, with AI assistance) labelled every headline blind
to model predictions, using this guide:
- *Event* = the primary event the headline reports. Price moves or opinion without a stated cause are
  General News; broker calls and price targets are Analyst Rating; tariffs, sanctions, wars and elections
  are Geopolitical; central banks, inflation, growth and commodities are Macroeconomic; court cases, probes
  and fines are Legal & Regulatory; recalls, strikes, outages, crashes and cyber incidents are Operational Risk.
- *Sentiment* = the implication for the subject's investors. Questions ("Is X a buy?") and mixed headlines
  are neutral. Tightening by a central bank is negative for equities.

Single-annotator labels contain judgement calls. Classes with fewer than 10 examples (Capital Markets,
Leadership Change) are reported but not interpreted.

## Timing assumptions

About 97% of archive headlines carry a **date only** (Google News stamps them at midnight US Pacific). The
backtest treats such a headline as usable only after that day ends, and the event study uses a two-day
window [D, D+1]. Corpus tweets have no timestamps at all, so in replay they are stamped with the replay clock
and they are never used in the backtest.

## Sources checked and not used

| Source | Why not |
|---|---|
| X/Twitter API | Paid only |
| Reddit, StockTwits, Bluesky public endpoints | Returned HTTP 403 to anonymous clients on 6 Oct 2026 |
| Kaggle datasets in the case-study list | Download requires an account; the MIT Hugging Face finance-tweet corpora cover the same need |
| NewsAPI | Needs a key; supported as an optional connector (`NEWSAPI_KEY` in `.env`) |
| GDELT history beyond ~3 months | The DOC API only searches a rolling window, and this IP was heavily throttled |
